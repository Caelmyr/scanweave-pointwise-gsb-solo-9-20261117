# 片坊 ScanWeave
档案扫描图像整理工作台。启动：docker compose up -d --build，打开 http://127.0.0.1:8912。
载入扫描样张为程序合成的橙色片基透射扫描；也可添加自己的PNG/JPEG/TIFF。现有扫描整理支持对齐、去噪、平面拼接、曝光融合、焦点合成、裁剪、白平衡、局部调整、质量检测、原始扫描留存、结果导出和版本恢复。
扫描档案保存批次标签、扫描设备、分辨率与素材哈希；这些档案不改变像素。每批最多24帧，处理长边最多1536，CPU处理；不表示真实设备色彩标定或高分辨率生产能力。
复用本地自有 StackLight 图像计算及版本引擎，新设计扫描样张、档案和页面。复用代码为项目自有，不声称全部从零编写；基础镜像使用本机已有依赖。
## 像素贡献溯源（仅解释，不改像素）
多帧降噪结果在查看器工具栏提供「像素溯源」：在合成预览上点击任意位置，即按该结果保存时的工程快照重新走一遍相同的准备、局部光流与降噪计算，给出每个启用帧在该像素的实际贡献份额、接纳/剔除状态与原因（Sigma 离群轮次、截尾剔除、中值未取、零权重、无覆盖等），并可打开带位置标记的对齐帧或原帧对照。停用异常帧并重新合成后，对新结果重新取点即得到更新解释；历史结果仍可解释并标注「已过期」。裁剪、旋转、翻转后的点击会映回同一处共同画布内容，未覆盖的帧不会显示为参与过计算。该功能只读取并重算解释数据，不写回、不改变任何结果像素，详见 `scanweave/explain.py`；`tools/verify_explain.py` 与 `tools/verify_trace_ui.mjs` 为端到端校验脚本。
