# 片坊 ScanWeave
档案扫描图像整理工作台。启动：docker compose up -d --build，打开 http://127.0.0.1:8912。
载入扫描样张为程序合成的橙色片基透射扫描；也可添加自己的PNG/JPEG/TIFF。现有扫描整理支持对齐、去噪、平面拼接、曝光融合、焦点合成、裁剪、白平衡、局部调整、质量检测、原始扫描留存、结果导出和版本恢复。
扫描档案保存批次标签、扫描设备、分辨率与素材哈希；这些档案不改变像素。每批最多24帧，处理长边最多1536，CPU处理；不表示真实设备色彩标定或高分辨率生产能力。
复用本地自有 StackLight 图像计算及版本引擎，新设计扫描样张、档案和页面。复用代码为项目自有，不声称全部从零编写；基础镜像使用本机已有依赖。

## 长幅条带拼接工作台（/strip-workbench）
针对一张长幅原稿分段扫描后文件顺序错乱的场景，提供独立工作台，强调“先建议、后确认、不强行拼合”：

- 导入一组有重叠的条带（纵向或横向接续），系统按图像内容两两分析邻接：ORB 特征确定接续方向，再在全重叠范围内做粗到精的归一化互相关（NCC）搜索，估计重叠量与扫描走位的次轴错位。
- 自动给出排列顺序与每条带在统一画布上的位置，并在页面上以可拖拽、可缩放的整幅布局呈现；可拖动条带、双击/按钮旋转、上移下移修改前后关系，修改后重新拼接。
- 无法确定邻接（无相邻匹配）、多个相近候选（歧义）、弱匹配、闭环矛盾、接缝间隙或明显错位时，生成带级别的疑点（错误/警告）并在条带与疑点面板标出，由人工确认或裁决邻接关系，而不是静默拼成看似完整的图。
- 布局确认前禁止导出整图；存在未处理的错误级疑点时无法确认。确认后导出的 PNG（16位）/TIFF/JPEG 严格按当前布局渲染，并可下载记录几何、素材哈希与疑点的布局清单 JSON。
- 非破坏性：原始扫描以内容哈希存入不可变素材库，旋转/摆放/拼接只读取像素、不改写不裁切；布局、分析结果、疑点与撤销历史单独保存在 sheets 目录，删除布局不影响素材。

测试：`python3 tests/test_strips.py`（核心求解与服务）、`tests/test_strips_advanced.py`（横向接续、走位、手动重排、旋转）、`tests/test_strips_e2e.py`（完整 HTTP 工作流与素材完整性）。
